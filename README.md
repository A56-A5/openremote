# 📒 OpenRemote

Lightweight, database-driven remote monitoring & interaction for local OpenCode agents.
No hosted backend — a Supabase project (Postgres + Realtime + Storage) is the sync layer; a tiny local worker bridges your machine; a scrapbook-styled web app is your remote window.

```
┌─────────────┐   SSE/REST    ┌──────────────┐   Postgres/Realtime   ┌──────────┐
│ OpenCode    │◄─────────────►│ openremote   │◄─────────────────────►│ Supabase │
│ (local)     │               │ worker (CLI) │                       └────▲─────┘
└─────────────┘               └──────────────┘                            │
                                                              ┌──────────┴─────────┐
                                                              │ web app (mobile)   │
                                                              └────────────────────┘
```

## Pieces

| Path        | What                                                       |
| ----------- | ---------------------------------------------------------- |
| `plugin/`   | `openremote` CLI + persistent worker (start/stop/status/pair) |
| `web/`      | React + Vite front end — paper-notebook UI, realtime feed    |
| `supabase/` | `schema.sql` — tables, RLS, pairing RPC, storage bucket      |
| `commands/` | `/opencode-remote` command file for OpenCode                 |

## Setup

1. **Supabase** — create a project, run `supabase/schema.sql` in the SQL editor. Copy the project URL + anon key.
2. **Worker on your computer**
   ```bash
   cd plugin && npm install && npm run build
   node dist/cli.js config --url https://XXX.supabase.co --key ANON_KEY
   node dist/cli.js install      # installs /opencode-remote into ~/.config/opencode/commands
   ```
3. In OpenCode: `/opencode-remote start` → prints a **pairing code**.
4. **Web app**
   ```bash
   cd web && npm install
   echo "VITE_SUPABASE_URL=https://XXX.supabase.co" > .env.local
   echo "VITE_SUPABASE_ANON_KEY=ANON_KEY" >> .env.local
   npm run dev
   ```
   Open it on your phone, enter the pairing code.

## Commands

```
/opencode-remote start            start the local worker (idempotent — one worker only)
/opencode-remote stop             stop worker, mark sessions offline
/opencode-remote status           worker + session state
/opencode-remote pair <CODE>      pair with a code generated by the web app (or vice versa)
```

CLI parity: `openremote start|stop|status|pair|config|install`.

## Data lifecycle

- Worker sweeps hourly: events older than `retention_days` (default 7) and completed/failed prompts + their storage objects older than the window are removed.
- **Pending / processing prompts are never deleted.**
- Web app: per-session wipe + manual clears in Settings.
